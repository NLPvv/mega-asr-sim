# ASR 声学增强说明

一条干净语音先转成 16 kHz 单声道。代码在波形上模拟房间、录音设备和传输链路带来的变化，输出 WAV，沿用原来的转写。输入清单每行包含 `audio` 和 `text`。 [批处理入口](../simulate.py#L85) · [运行示例](../README.md#quickstart)

## 同一句话听一遍

先听[原声](https://nlpvv.github.io/mega-asr-sim/demo/#clean)，再听[仅低通](https://nlpvv.github.io/mega-asr-sim/demo/#lowpass)和[仅高通](https://nlpvv.github.io/mega-asr-sim/demo/#highpass)。两份都用 1.5 kHz 截止频率。低通削弱高频，「丝」这类声音会发闷。高通削弱低频，人声听起来更薄。

把相邻两点取平均，可以直观地理解低通怎么压住快速变化。从原值减去平均值，留下的快速变化就像高通的结果。项目用四阶 Butterworth 滤波器，由 `butter` 算系数，`sosfilt` 按系数逐点处理。截止频率附近逐渐衰减，重复滤波会加强衰减。 [滤波实现](../primitives.py#L136)

七种效果各自从同一份原声开始，`m=0.5`，保留各场景的响度差。可以[在线播放全部 10 条](https://nlpvv.github.io/mega-asr-sim/demo/)，也可以点下表跳到对应的播放器。 [样例实际参数](demo/parameters.json)

## 七种效果

参数在 [`ATOMIC_CHAINS`](../atomic.py#L22) 中按执行顺序定义。`F(v)` 是固定值，`R(a, b, True)` 随严重度 `m` 从 0 到 1 把值从 `a` 调到 `b`，`False` 则反向。`I` 用同样的方法算出整数参数。下表箭头都按 `m=0 → 1` 阅读。 [参数解析](../severity.py#L28)

| 效果 | 现实中的现象与代码做法 | 关键参数 |
| --- | --- | --- |
| **噪声** [试听](https://nlpvv.github.io/mega-asr-sim/demo/#noise) | 说话声和空调声一起到达麦克风，声压叠加。`add_noise` 把同长度的噪声按 SNR 缩放后逐点加到语音上，再调响度。 [实现](../primitives.py#L49) | SNR **10 → −5 dB**，目标 **−23 LUFS**。 [配置](../atomic.py#L23) |
| **远场** [试听](https://nlpvv.github.io/mega-asr-sim/demo/#far_field) | 手机移到屋子另一头，直达声变弱，房间反射相对明显。`add_reverb` 用卷积叠加不同延迟的语音副本，再做低通、调响度。 [实现](../primitives.py#L81) | `room_size` **0.4 → 0.6** 控制合成混响尾长，混响权重 **0.4 → 0.5**，直达权重 **0.5**。低通 **4.5 → 3.5 kHz，3 次**，目标 **−27 → −38 LUFS**。 [配置](../atomic.py#L29) |

## 用小数组看波形怎么变

下面取 `m=0.5`，每个例子只算关键一步。完整处理顺序见上表。

**噪声**。原声和噪声的 RMS 相同，目标 SNR 为 2.5 dB，噪声乘约 0.75 后逐点相加。

```text
原声                 [0.20,  0.40, 0.60, 0.00, 0.00]
噪声                 [0.20, -0.40, 0.00, 0.60, 0.00]
原声 + 0.75 × 噪声 ≈ [0.35,  0.10, 0.60, 0.45, 0.00]
```

**远场**。把原声简化为一个脉冲，假设房间响应为 `[1, 0.30, 0.10]`。直达声先到，两份反射分别晚 1 点、2 点。卷积结果的峰值和原声恰好都是 0.60，可以直接混合。

```text
原声                        [0.60, 0.000, 0.000]
卷积结果（直达声和反射）    [0.60, 0.180, 0.060]
0.5 × 原声 + 0.45 × 卷积结果 [0.57, 0.081, 0.027]
```

实际代码用更长的合成房间响应，卷积后先把峰值对齐再混合。`room_size` 控制合成尾音的长短。

**遮挡**。取一段持续高低交替的波形中间 4 个点。1.75 kHz 低通做三次后，快速跳动几乎被压平。混回 10% 原声后，还有少量起伏。

```text
原声                        [0.30, 0.10, 0.30, 0.10]
低通后                    ≈ [0.20, 0.20, 0.20, 0.20]
90% 滤波结果 + 10% 原声   ≈ [0.21, 0.19, 0.21, 0.19]
```

**回声混响**。先做混响和高通。单看最后的回声步骤，把它的输入简化为一个脉冲，回声间隔缩成 2 点。第一次的权重是 `mix × feedback = 0.25 × 0.4 = 0.10`，之后每次再乘 0.4。

```text
进入回声步骤   [0.60, 0, 0.00, 0, 0.000]
叠上回声后     [0.60, 0, 0.06, 0, 0.024]
```

实际间隔为 200 ms，在 16 kHz 下相当于 3200 点。

**录音退化**。`m=0.5` 达到重采样门槛。用同一段交替波形看重采样这一步，降到 8 kHz 时先削弱高频，升回去时从剩下的波形补点。

```text
16 kHz 原声   [0.30, 0.10, 0.30, 0.10, …]
降到 8 kHz  ≈ [0.20, 0.20, …]
升回 16 kHz ≈ [0.20, 0.20, 0.20, 0.20, …]
```

**失真**。先按 40 dB 放大 100 倍，再用 `tanh` 压峰、乘 1.2 并裁到 `[-1, 1]`。超出范围的采样值被压在边界。

```text
原声                [-0.200, -0.005, 0, 0.005, 0.200]
放大后              [-20.00, -0.500, 0, 0.500, 20.00]
压峰并裁幅后      ≈ [-1.000, -0.555, 0, 0.555, 1.000]
```

**丢帧**。用 `|` 分隔帧，每帧只写 2 个点。假设触发后选中了第 2、3 帧，两帧都用静音或同一份上一帧覆盖。实际每帧是 20 ms、320 个点。

```text
原声         [0.20, 0.40 | 0.60, 0.50 | -0.30, -0.10 | 0.10, 0.20]
填静音       [0.20, 0.40 | 0.00, 0.00 |  0.00,  0.00 | 0.10, 0.20]
复制上一帧   [0.20, 0.40 | 0.20, 0.40 |  0.20,  0.40 | 0.10, 0.20]
```

## 加噪时怎么算 SNR

长噪声随机裁一段，短噪声循环补齐。设 $x_t$ 是当前语音的第 $t$ 个采样值，$n_t$ 是对齐后的噪声采样值，$t$ 从 1 到总点数 $T$，$s$ 是目标信噪比（dB）。

$$
\begin{aligned}
\mathrm{RMS}(z) &= \sqrt{\frac{1}{T}\sum_{t=1}^{T}z_t^2} \\
\alpha &= \frac{\mathrm{RMS}(x)}{\mathrm{RMS}(n)\,10^{s/20}} \\
y_t &= x_t + \alpha n_t
\end{aligned}
$$

$z$ 代表任一段波形，$z_t$ 是它的采样值，RMS 是整段波形的均方根幅值。$10^{s/20}$ 把 dB 转成幅值比，$\alpha$ 是噪声缩放倍数，$y_t$ 是相加后的采样值。代码用 $s=10-15m$。到 **−5 dB** 时，噪声 RMS 约为当前语音的 **1.78 倍**，有些字会被盖住。这个 SNR 针对本次混入步骤，后续滤波或削波会改变最终听感。 [加噪实现](../primitives.py#L49)

## 54 个场景怎么用

7 个单项、18 个双项、13 个三项、13 个四项、3 个五项。远场、遮挡、回声混响互斥。`--scenario random` 按输入顺序轮转这 54 个场景，每句生成一份。默认 `--mapping linear` 为每句均匀抽取 `m`，也可以用 `--severity 0.5` 固定。 [枚举与合并](../scenarios.py#L36) · [命令行参数](../simulate.py#L104)

- `recording+noise` 先做录音退化，再混入环境噪声。第二次加噪按已经带白噪声的波形计算 RMS。
- `far_field+recording` 先做远场，再接重采样和白噪声。跨效果遇到同名算子时保留先出现的配置，加噪允许重复，因此录音退化的滤波和响度步骤被跳过。 [处理链合并](../scenarios.py#L77)

试听原声取自 Germartin1 的普通话录音，按 CC0 发布。噪声示例使用合成底噪，其余处理使用本仓库代码。 [录音来源](https://commons.wikimedia.org/wiki/File:Introduction_In_Chinese.ogg) · [CC0](https://creativecommons.org/publicdomain/zero/1.0/)
