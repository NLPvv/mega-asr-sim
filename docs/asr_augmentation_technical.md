# ASR 加噪数据增强说明

当前项目通过修改语音波形生成增强数据，采样率保持不变，转写保持不变，原始音频保留，增强结果单独存放。

## 1. 数据怎么放

```text
data/<split>/clean.jsonl    # 原始语音路径和转写
data_noise/corpora/<corpus>/                 # 原始噪声库
data/noise_pools/{train,dev,test} # 分好的噪声池
out/<split>/                          # 增强音频、manifest 和错误记录
```

每个 `clean.jsonl` 一行对应一句语音，包含 `audio` 和 `text`。三个 train 子集使用 train 噪声池，dev、test 分别使用自己的噪声池，不混入训练集。输出统一为 16 kHz、单声道、PCM16 WAV。

## 2. 每句语音分配什么增强

原始语音按整理的清单顺序处理，脚本不会自动打乱。

`--scenario random` 的实际做法是让 54 个场景轮流分配：第 1 句用 `noise`，第 2 句用 `far_field`，第 55 句再用 `noise`。每句只生成一份增强音频。

随机的是增强严重度、噪声文件，以及长噪声的裁剪位置。噪声按文件均匀抽取，文件多的库被抽中的机会也更多。

## 3. 噪声怎么混进去

随机选一段噪声，将语音和噪声统一为 16 kHz 单声道。长噪声随机裁剪和语音长度一致，短噪声循环补齐，使两者长度一致；抽到静音片段就重新选择。

设当前输入语音为 $x_t$，噪声为 $n_t$，长度为 $T$，目标信噪比为 $s$，单位是 dB：

$$
\begin{aligned}
\mathrm{RMS}(z) &= \sqrt{\frac{1}{T}\sum_{t=1}^{T}z_t^2} \\
\alpha &= \frac{\mathrm{RMS}(x)}{\mathrm{RMS}(n)\,10^{s/20}} \\
y_t &= x_t + \alpha n_t
\end{aligned}
$$

公式中的符号：

| 符号 | 含义 |
| --- | --- |
| $t$ | 采样点的位置，从 1 到 $T$ |
| $T$ | 总采样点数，例如 1 秒、16 kHz 音频有 16000 个点 |
| $z$、$z_t$ | 任意一段波形及其第 $t$ 个采样值；$z$ 可以是语音 $x$ 或噪声 $n$ |
| $\mathrm{RMS}(z)$ | 波形的均方根幅值，即逐点平方、求平均、再开方 |
| $x_t$ | 当前加噪步骤输入波形的第 $t$ 个采样值，可能已经过其他增强 |
| $n_t$ | 长度对齐后、尚未缩放的噪声采样值 |
| $s$ | 目标信噪比，单位 dB；越大表示语音相对越强 |
| $\alpha$ | 噪声缩放系数，决定把噪声放大或缩小多少倍 |
| $y_t$ | 语音与噪声相加后的采样值 |

$10^{s/20}$ 将 dB 表示的信噪比转换为 RMS 幅值比；$\sum$ 表示对所有采样点求和。

先根据语音和噪声的能量计算缩放系数 $\alpha$，再把缩放后的噪声叠加到语音上。SNR 越低，噪声相对越大。

当前 SNR 随严重度 $m$ 变化，$m$ 是 0 到 1 之间的增强强度：

$$
s = 10-15m,\qquad m\in[0,1]
$$

例如，`m=0.2` 对应 7 dB，`m=0.5` 对应 2.5 dB，`m=1` 对应 −5 dB。这里按整段 RMS 计算；复合场景后续的滤波、失真或再次加噪，会改变最终音频相对原始语音的 SNR。

## 4. 场景怎么组合

项目用噪声、远场、遮挡、回声混响、录音退化、失真、丢帧这 7 类效应，预定义了 54 个场景。远场、遮挡、回声混响互斥，其余效应按配置组合。每句使用同一个严重度控制各项参数。

例如：

`far_field` 用来模拟远场收音，依次做三件事：加混响、低通滤波削弱高频、降低响度。

`recording` 用来模拟录音退化：按概率做一次 16 kHz→8 kHz→16 kHz 重采样，再加白噪声、做高通和低通滤波、调整响度。重采样用于模拟带宽损失，最终文件仍是 16 kHz。

组合场景是在同一条波形上连续处理。`recording+noise` 就是先对干净语音做 `recording`，再在这个结果上加入真实环境噪声`noise`：

```text
干净语音 → 带宽退化（概率触发）→ 白噪声 → 高通、低通
         → 响度调整 → 真实环境噪声
```

最后一次加噪时，公式中的 $x$ 已经是经过 `recording` 的波形，里面也已经含有白噪声。因此，当前目标 SNR 不等于原始干净语音相对两种噪声的最终 SNR。

`far_field+recording` 也是先远场、再录音退化，但代码会按算子名称去重：远场已经做过滤波和响度调整，`recording` 中对应的处理会跳过，只追加重采样和白噪声：

```text
干净语音 → 混响 → 低通滤波 → 降低响度
         → 带宽退化（概率触发）→ 白噪声
```

同类算子跨效应重复时保留第一次出现的参数，加噪允许重复。
